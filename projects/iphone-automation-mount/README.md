# iPhone automation mount

This project folder contains the iPhone automation mount materials that were previously grouped under `tools/`.

## Contents

- [`../iphone-bed-mount/`](../iphone-bed-mount/) — the iPhone bed-mount generator and prompt files.
- [`../prusa-mini-stylus-holder/`](../prusa-mini-stylus-holder/) — Prusa Mini stylus holder variations.

## Usage

Open the relevant project folder in Autodesk Fusion 360's Scripts and Add-Ins panel and run the Python script you need.
