# Design Prompt: Prusa Mini iPhone Bed Mount

Create a parametric Autodesk Fusion 360 Python script named `iphone-bed-mount.py`.

Rather than hardcoding static sketch coordinates, define high-level primary design parameters at the top and calculate all boundaries, offsets, and cutouts relationally through parametric geometry.

The project creates a single-piece, rigid 3D-printable test automation fixture that mounts an iPhone SE (2nd Gen) directly to the heated bed of a Prusa Mini 3D printer so the phone moves with the printer.

This is the model kept in the dedicated `projects/iphone-bed-mount/` folder.
