# CAD projects

This directory contains the project-specific Fusion 360 design generators and related prompt files, separated from the utility tooling in `tools/`.

## Project catalog

- [`iphone-automation-mount/`](./iphone-automation-mount/) — overview and documentation for the iPhone automation mount project.
- [`iphone-bed-mount/`](./iphone-bed-mount/) — parametric iPhone bed mount for a Prusa Mini printer.
- [`prusa-mini-stylus-holder/`](./prusa-mini-stylus-holder/) — stylus holder variations for the Prusa Mini toolhead.

## Notes

- Keep project-specific CAD files in dedicated project folders rather than under `tools/`.
- Use `tools/` for utilities such as Fusion MCP Studio and other developer support scripts.
