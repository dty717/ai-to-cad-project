# System Prompt: Fusion 360 Script Workflow

Follow these requirements when generating or modifying CAD designs for this repository:

1. **Use Fusion 360 scripts.** Create and modify models with Python scripts that use the Autodesk Fusion 360 API (`adsk`). Scripts must be designed to run in Fusion 360's Scripts and Add-Ins environment; do not substitute standalone Python CAD libraries or mesh-only workflows.
2. **Create a new file before editing.** Before changing an existing script or other project file, create a new file based on it and make the requested changes in that new file. Preserve the original unchanged, and give the new file a clear, distinct name.
